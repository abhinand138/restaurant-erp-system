# 🍽️ Restaurant ERP System

A modern full-stack Restaurant ERP application built using React, Spring Boot and PostgreSQL.

## Features

* Landing Page
* Login System
* Role Based Access Control
* Dashboard
* Table Management
* Menu Management
* Order Management
* Billing Management
* Analytics Dashboard
* Protected Routes

## User Roles

### Admin

* Dashboard
* Tables
* Menu
* Orders
* Billing
* Analytics

### Manager

* Dashboard
* Tables
* Menu
* Orders
* Analytics

### Cashier

* Dashboard
* Orders
* Billing

## Technology Stack

### Frontend

* React
* React Router
* Axios
* Tailwind CSS

### Backend

* Spring Boot
* Spring Security
* Spring Data JPA

### Database

* PostgreSQL

## Project Structure

Frontend → React

Backend → Spring Boot

Database → PostgreSQL
